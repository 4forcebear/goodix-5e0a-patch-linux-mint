# Native software tests

On x86_64 Linux, install Nix with a working `<nixpkgs>` channel or `NIX_PATH`,
plus Bash and Python 3. The suite uses Python's standard library. No sensor,
root access, fprintd, or suspend is needed. Nix needs access to its daemon/store
and network access for sources and dependencies not already cached.

From a checkout:

```sh
bash tests/fixtures/runner_summary/run_check.sh
bash tests/fixtures/native_lane/run_check.sh
bash tests/run_all_tests.sh
```

The runner defaults to `GOODIX_NATIVE_TESTS=required`. It builds the fake-device
C harness before discovery and fails if the build fails or the executable is
missing. It never uses `/tmp/test_ssm_teardown` or `/tmp/libfprint-goodix` for
this lane. Other tests may explicitly skip checks of external developer trees.
The summary counts skips separately from executed/passed tests.

`scripts/native-harness.nix` reuses `libfprint-goodix.nix`: its fixed upstream
revision/hash, repository patch, Meson options, compiler and dependencies
including GLib, GUsb, libusb, Pixman, OpenSSL, NSS/NSPR and introspection tools.
It compiles and runs the eight simulated SSM/cancellation invariants and a
production protocol-codec checksum round-trip across all 256 command bytes
during the Nix build. Both executables are packaged; the SSM binary uses its
library RUNPATH. Store paths are generated by Nix, not copied from a developer
machine.

The same build runs `test_milan_raster` against the production bridge with
algorithm exports stubbed. It checks all 5,120 transposed pixels at quality,
enrollment, verification and gallery calls, buffer lifetime, gallery error
cleanup and the existing positive-score match decision. No DLL or sensor is used.

`scripts/suspend-harness.nix` also compiles the production driver with mocked
transport. It checks lifecycle recovery and frame normalization: contact and
flat-frame rejection, band-pass edge behavior, an analytic impulse response and
saturation. It also checks tagged-print round trips and rejects incompatible
or malformed saved prints. The frame
checks use synthetic pixels, not private captures or a Python implementation.

CI runs these checks plus installer/cleanup fixtures and a downstream fprintd
build in the `Required native software tests` job with
`GOODIX_NATIVE_TESTS=required`, without a skip or continue-on-error fallback.
The downstream build catches API/version incompatibilities the driver harness
cannot; run it locally with:

```sh
nix-build --no-out-link -E 'let pkgs = import <nixpkgs> {}; in pkgs.fprintd.override { libfprint = pkgs.callPackage ./libfprint-goodix.nix {}; }'
```

Repository branch protection must select that job if merging is to require it.
To use the same nixpkgs revision as CI:

```sh
export NIX_PATH=nixpkgs=https://github.com/NixOS/nixpkgs/archive/b1b875982b17dabde9b4a37f3e229e74913e6db3.tar.gz
bash tests/run_all_tests.sh
```

For a single native test:

```sh
export GOODIX_NATIVE_HARNESS="$(bash scripts/build_native_harness.sh)"
python3 -m unittest tests.tier5_adversarial.test_m1_c1_lifecycle_adversarial.TestM1C1LifecycleAdversarial.test_native_c_ssm_and_cancellation_invariants -v
```

For local Python-only work without Nix, explicitly opt out:

```sh
GOODIX_NATIVE_TESTS=skip bash tests/run_all_tests.sh
```

That command prints and counts the native skip. It is not a required-lane pass.
These tests do not establish hardware behavior or release readiness.
